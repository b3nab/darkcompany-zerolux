# Storage

The workspace's files where they are. Each **location** is a folder on this computer, a Google Drive, an S3 bucket or any other provider's place, with as many as you want, several of one provider too. Every location shows what its service holds, live: nothing is copied into ZeroLux.

## What you can do

- Browse, upload, rename, move, copy and delete files in Files, and search the locations that can.
- Share a file in a chat: it stays in its location, and the chat shows it.
- Let agents read and write files through the same actions as people.

## Locations

- **ZeroLux**, a folder of the workspace's own, is there from the start.
- **Folder**: any folder on the computer ZeroLux runs on.
- **Google Drive** and **S3** come with their own extensions.

Add one in Files with **Add location**. Removing a location forgets it in ZeroLux; its files stay where they are.
